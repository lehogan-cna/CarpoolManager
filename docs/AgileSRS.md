# Agile Software Requirements Specification
*Note that below is not for this project*

## Functional Requirements

### FR1 User Registration

Users shall be able to create accounts.

### FR2 User Authentication

Users shall be able to log in and log out.

### FR3 Create Ride

Drivers shall be able to create ride offers.

### FR4 Search Rides

Passengers shall be able to search available rides.

### FR5 Request Ride

Passengers shall be able to request a seat.

### FR6 Manage Requests

Drivers shall be able to accept or reject ride requests.

## Non-Functional Requirements

### Performance

Ride searches should return results within 3 seconds.

### Security

Passwords must be encrypted.

### Reliability

System availability target of 99%.

### Usability

Typical users should be able to post a ride in under 2 minutes.

## Constraints

- 8-week development schedule.
- Developed using Scrum.
- Hosted in GitHub.
